# 主軸案例：陸平抽脂致死案

## 案情（白話）
- 2013年6月23日，醫師林玉清設立的診所裡，三名醫師（林玉清、周建國等）和**不具任何醫事人員資格、從事醫美器材買賣**的池國樑（原名池岳龍），以及鄭惠升，一起替被害人陸平做大範圍麻醉抽脂（大腿、臀部、腰腹、手臂、背部）和自體脂肪豐胸手術
- 診所沒有大範圍麻醉手術需要的生命徵象監測儀器和急救設備
- 手術中被害人抽搐、躁動；池國樑幫她按摩腳部穴道，林玉清給氧氣、糖水、輸液，沒有及時轉送醫院
- 被害人7月25日因缺氧性腦症併發肺炎致神經敗血性休克死亡

## 歷審（刑事）
| 審級 | 字號 | 結果 |
|---|---|---|
| 一審 | 臺北地院104年度醫訴字第6號 | 有罪（細節待查） |
| 二審 | 臺灣高等法院106年度醫上訴字第5號 | 業務過失致死＋密醫罪，想像競合從一重論醫師法28條；林玉清2年、池岳龍2年2月 |
| 三審 | [[最高法院107台上4587]] | **撤銷發回**：過失行為、因果關係論證不足；醫療法82條適用於無資格者 |
| 更一審 | 臺灣高等法院108年度醫上更一字第1號 | 有罪（細節待查） |
| 三審 | [[最高法院111台上3499]] | **確定**：兩罪想像競合，從一重論醫師法28條；林玉清2年5月、池國樑2年9月 |
| 另案被告 | [[最高法院114台上27]]（鄭惠升） | **撤銷發回**：注意義務、預見可能性未具體論證 |

⚠️ 二審刑度（2年／2年2月）和確定刑度（2年5月／2年9月）不同，原因待查（更一審可能重新量刑）。

## 為什麼適合當主軸案例
1. 同時包含**醫師和非醫師**共同執行手術 → 可以比較兩種人的過失標準（爭點1）
2. 法院明確採**想像競合、從一重論密醫罪** → 致死結果在主文中消失（爭點2）
3. 最高法院兩度撤銷發回 → 呈現「密醫的過失怎麼認定」在實務上的困難
