# 密醫報告 wiki

期末報告〈「非醫師」的醫療過失：密醫案件中醫師法第28條與過失致死罪的競合問題〉的文獻資料庫與寫作進度網站。

🌐 **網站**：`https://<你的帳號>.github.io/<repo名稱>/`（開啟 GitHub Pages 後才會有）

## 功能
- 📅 首頁儀表板：截止日倒數、待辦完成度、資料卡查證統計
- 🕸️ 關係圖：法條、判決、文獻、爭點之間的連結，可以依爭點篩選
- 🗂️ 卡片總表：依類型、爭點、查證狀態（✅／⚠️）篩選
- 📖 名詞提示：法律術語旁邊有虛線，滑鼠移上去（手機點一下）就會顯示白話解釋
- 🔍 全文搜尋

## 資料夾
| 位置 | 內容 |
|---|---|
| `00_總覽.md` | 首頁 |
| `法條/` `判決/` `文獻/` `爭點/` | 資料卡（Markdown，可以用 Obsidian 編輯） |
| `草稿/` | 初稿、參考文獻（APA） |
| `AGENTS.md` | 給 AI 助理的使用說明 |
| `raw/` | 原始資料 |
| `index.html` `assets/` | 網站程式（一般不用動） |
| `tools/build_index.py` | 產生網站索引 |

## 如何更新
1. 用 Obsidian 或任何編輯器修改 `.md` 檔（或請 AI 幫你改）
2. 新增或改名卡片後，雙擊 `預覽.bat`（或執行 `python tools/build_index.py`）更新索引
3. 推到 GitHub，網站約 1 分鐘後更新

（進階，選用：把 `tools/選用_自動部署.yml` 放到 `.github/workflows/`，並把 Pages 來源改成 GitHub Actions，推送時就會自動重建索引。）

本機預覽：Windows 雙擊 `預覽.bat`（需要先安裝 Python），然後打開 http://localhost:8000

## 聲明
本網站為課程報告的學習筆記，判決資料取自司法院裁判書系統，學說摘要為筆者自行整理，不構成法律意見。
