# 爭點1：密醫的「過失」用什麼標準判斷？

## 問題
密醫害死病人時，要成立過失致死，必須證明他「違反注意義務」。那他應該盡到什麼程度的注意？
- (A) **醫師的標準**：做醫療行為就要達到合格醫師的水準
- (B) **醫療法第82條的寬鬆標準**：違反注意義務 **且** 逾越合理臨床專業裁量
- (C) **一般人的標準**：只用刑法第14條判斷
- (D) **承擔過失**：明知自己沒能力還接下醫療行為，這個「接手」本身就是過失

## 實務
| 判決 | 見解 |
|---|---|
| [[最高法院107台上4587]] | 無資格者和醫師共同手術 → 仍是醫療行為 → **適用第82條** |
| [[最高法院107台上4587]] | 不能只因為無照就認定有過失（無照駕駛類比） |
| [[最高法院114台上27]] | 共同手術時每個人的注意義務要個別認定；保證人地位 ≠ 注意義務 |

## 學說
| 文獻 | 見解 |
|---|---|
| [[評釋_107台上4587_醫療法82條限縮醫療過失]] | 第82條**不應適用**於密醫 |
| [[李貞瑩_醫療法第82條修法後實務之應用]] | 第82條只是明文化，沒有真的放寬 |
| [[黃則瑜_論醫療過失的判斷基準]] | 修法偏向保護醫療提供者 |

## 我的分析方向（草稿）
1. **文義**：第82條寫「醫事人員」，醫療法第10條定義醫事人員須領有證書 → 文義上不含密醫
2. **立法目的**：保護醫師的專業裁量、減少防禦性醫療 → 密醫沒有「專業裁量」可言，讓他享有這個保護不符立法目的
3. **第4項的問題**：「醫療設施、工作條件」納入考量 → 密醫常在簡陋環境行醫，反而因此**降低**標準？這是很強的反面論證
4. **承擔過失**：密醫明知沒能力而執行，接手本身就違反注意義務 → 但要小心不能變成「密醫＝當然有過失」（107台上4587的無照駕駛類比）
5. **107台上4587的特殊性**：本案有醫師一起做；密醫單獨行醫時，判決的理由還站得住嗎？
