# 爭點3：密醫罪是「集合犯」，競合怎麼判斷？

## 問題
- 實務認為：「執行醫療業務」本來就包含反覆、延續實施的意思 → 密醫看了100個病人，也只算**一個**密醫罪（集合犯）
- 如果其中一個病人死了：這次手術既是整段密醫罪的一部分，也是過失致死行為 → 實務因此認為兩罪「行為局部重疊」，論以想像競合
- 但這樣會不會讓一個很短的過失致死，被一段很長的營業行為「吸收」？

## 實務
- 集合犯：最高法院100台上5169、103台上10（⚠️ 下級審轉引，待查原文）
- 檢察官曾主張密醫應「按次計算、分論併罰」，被法院駁回（臺灣高等法院113醫上訴6，⚠️ 待讀）
