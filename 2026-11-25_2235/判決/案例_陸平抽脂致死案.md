# 主軸案例：陸平抽脂致死案

## 案情（白話）
> 依 [[最高法院114台上27]] 轉述的原判決事實欄，以及 [[最高法院111台上3499]]

**人物**
- 陸平：被害人，微笑國際診所員工
- 池國樑（原名池岳龍）：**不具醫師資格**，經營美麗安公司、從事醫美器材買賣
- 林玉清：醫師，微笑診所負責人
- 周建國：原審判決確定；鄭惠升：114台上27 上訴人（兩人資格依各判決為準，待核對）

**時間軸**
| 時間 | 發生什麼事 |
|---|---|
| 手術前 | 池國樑以宣傳診所門面、將來開分店給予區長職位等說法，勸說沒有醫療必要的陸平接受抽脂、豐胸（111台上3499；⚠️ 請對照原文） |
| 102年6月23日 17:40 | 在微笑國際診所（後更名琦美診所）門診手術室開始手術 |
| 第一階段：抽脂（約到19～20點） | 周建國、林玉清、池國樑、鄭惠升陸續操作微管抽脂；證人說抽脂後陸平在旁邊喝飲料，意識清醒 |
| 第二階段：豐胸回填 | 池國樑、林玉清、周建國在左胸、右胸施打局部麻醉針（lidocaine），劑量逾合理範圍；沒有使用生命徵象監測儀器、血氧機 |
| 同日約 21:45 | 陸平出現癲癇症狀（證人：池國樑打完麻醉針後開始躁動） |
| 現場處置 | 沒有置放氣管內管接呼吸器，也沒有給抗癲癇、鎮靜藥物；只給鼻導管氧氣、生理食鹽水點滴、營養液、穴道按摩 |
| 之後 | 癲癇重積發作 → 缺氧性腦病變 → 送國泰醫院急救，再轉臺北榮總 |
| 102年7月25日 | 缺氧性腦症併發肺炎，致神經敗血性休克死亡 |

**⚠️ 設備問題：兩則判決說法不同**
- 114台上27 轉述鄭惠升案的原判決：診所「未備置必要之設備」
- 111台上3499（林玉清、池國樑案）：第一審認定沒有充足急救設備是事實認定錯誤；現場照片顯示手術室似有監測儀器及血氧機，過失在於**沒有立即使用**
- → 報告寫「**有設備卻沒有使用**」，不要寫「診所沒有設備」

| 審級 | 字號 | 結果 |
|---|---|---|
| 一審 | 臺北地院104年度醫訴字第6號 | 有罪（細節待查） |
| 二審 | 臺灣高等法院106年度醫上訴字第5號 | 業務過失致死＋密醫罪，想像競合從一重論醫師法28條；林玉清2年、池岳龍2年2月 |

| 更一審 | 臺灣高等法院108年度醫上更一字第1號（111年4月20日） | 有罪，想像競合從一重論醫師法28條（刑度待查） |
| 三審 | [[最高法院111台上3499]]（112年8月24日） | **撤銷自為判決（確定）**：駁回檢察官「分論併罰」主張，兩罪想像競合從一重論醫師法28條；適用新法並依速審法第7條減刑；林玉清2年5月、池國樑2年9月 |
| 另案被告 | [[最高法院114台上27]]（鄭惠升，114年2月27日） | **撤銷發回**：注意義務、預見可能性未具體論證 |
| 更一審（鄭惠升） | 臺灣高等法院114年度重醫上更一字第1號（114年12月10日） | ❓ 結果待讀（結稿前補） |

⚠️ 二審刑度（2年／2年2月）和確定刑度（2年5月／2年9月）不同。111台上3499 是最高法院自己改判（含速審法減刑），更一審原本判多少還待查。

## 為什麼適合當主軸案例
1. 同時包含**醫師和非醫師**共同執行手術 → 可以比較兩種人的過失標準（爭點1）
2. 法院明確採**想像競合、從一重論密醫罪** → 致死結果在主文中消失（爭點2）
3. 最高法院兩度撤銷發回 → 呈現「密醫的過失怎麼認定」在實務上的困難
